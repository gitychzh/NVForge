# R1264 — hm4104 fallback 修正: ms_gw→dsv4f0731_nv40666

> **Date**: 2026-08-15
> **Scope**: hm4104 (cc-adapter), docker-compose.yml env
> **Request**: 核对 hermes 模型链路 hm4104 → oc45001(primary) + dsv4f0731_nv40666(fallback), 修正 fallback 配置

## 背景

用户要求核对 hm4104 的模型链路:
- **Primary**: hm4104 → oc45001 (big-pickle, opencode zen 免费模型) ✅ 已正确
- **Fallback**: hm4104 → dsv4f0731_nv40666 (dsv4f0731_nv, NVCF pexec) ❌ 仍指向 ms_gw:40007

发现 docker-compose.yml 中 hm4104 的 fallback 配置为历史残留:
- `FALLBACK_URL=http://ms_gw:40007/v1` (应改为 dsv4f0731_nv40666:40666)
- `FALLBACK_MODEL=dsv4f0731_ms` (应改为 dsv4f0731_nv)
- 无 `FALLBACK_API_KEY` (dsv4f0731_nv40666 入站 Bearer=nv-gw-token)

## 改动

**文件**: `/opt/cc-infra/docker-compose.yml` (hm4104 service)
**备份**: `docker-compose.yml.bak.20260815_hm4104_fb`

| 字段 | 改前 | 改后 |
|---|---|---|
| `FALLBACK_URL` | `http://ms_gw:40007/v1` | `http://dsv4f0731_nv40666:40666/v1` |
| `FALLBACK_MODEL` | `dsv4f0731_ms` | `dsv4f0731_nv` |
| `FALLBACK_API_KEY` | (无) | `nv-gw-token` |
| `MS_GW_API_KEY` | `ms-gw-token` (无注释) | `ms-gw-token` (保留兼容, ms_gw 不再是 fallback 目标) |
| `depends_on` | `nv_gw` | `dsv4f0731_nv40666` + `nv_gw` (保留历史依赖) |

## 应用方式

env 改动 → `docker compose up -d hm4104` (非 restart, restart 不加载新 env)
